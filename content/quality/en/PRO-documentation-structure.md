# PRO-000 Documentation Structure and Implementation Plan

## 1. Purpose
This document shows how the food safety and quality system documentation at [SITE NAME] is structured, which package documents address which requirements, which documents the site must prepare itself, and how to implement the system step by step in about 12 weeks.

## 2. Scope
It covers the whole PRO package: top-level document, hazard analysis, procedures, instructions, forms and records. It is intended for the Quality Manager and the implementation team.

## 3. Definitions
- **PRO package**: a set of ready-to-adapt system documents (QM, HA, PR, IN).
- **Site-specific documents**: documents that cannot be prepared in advance because they depend on specific products and equipment (e.g. flow diagrams, specifications, cleaning cards).
- **Gap analysis**: comparison of the current state with requirements to identify what must be added.

## 4. Responsibilities
- Site Director: approves the implementation schedule and provides resources.
- Quality Manager: leads implementation, adapts documents, reports progress.
- Department managers: provide process data, assign record owners, train staff.

## 5. References
- Regulation (EC) No 852/2004, Article 5.
- BRCGS Food Safety Issue 9; IFS Food version 8; ISO 22000:2018.
- QM-001 (top-level document), PR-001 (document control).

## 9. Implementation plan (about 12 weeks)
| Week | Stage | Activities | Output |
|---|---|---|---|
| 1 | Start | appoint team, gap analysis (Appendix 1), schedule | approved plan |
| 2 | Foundations | QM-001: policy, objectives, organisation; PR-001: coding, document register | documentation system |
| 3–4 | HACCP | product descriptions, flow diagrams confirmed on the floor, hazard analysis, CCPs (HA-001) | HACCP plan |
| 4–5 | PRPs | IN-001 cleaning cards, PR-007 hygiene and training, PR-008 pest control and storage, PR-009 glass and calibration | working prerequisite programmes |
| 5–6 | Allergens and labels | PR-005 matrix and risk assessment, PR-012 label checklist | labels verified |
| 6–7 | Suppliers | PR-002: raw material risk assessment, questionnaires, approved supplier list | supplier list |
| 7–8 | Product control | PR-010, PR-017 testing plan, PR-016 for new products | testing plan |
| 8–9 | Response | PR-003, PR-004 traceability test, PR-011, PR-013 contacts and continuity plan | traceability test completed |
| 9–10 | Defence and authenticity | PR-014 threat assessment, PR-015 vulnerability assessment | assessments approved |
| 10–11 | Training and records | training on all procedures, records kept for at least 4–6 weeks | evidence of implementation |
| 11–12 | Check | full-system internal audit (PR-006), CAPA, management review | audit readiness |

Before a certification audit the system should be operating with records covering an appropriate period (certification bodies usually expect at least several months of records; confirm with the body).

## 10. How to adapt a package document
1. Replace all fields in square brackets [ ] with site data.
2. Remove items that do not apply (e.g. Listeria monitoring where there are no ready-to-eat products) and record the rationale in the hazard analysis.
3. Check that the description matches how the work is actually done; if not, change either the description or the practice.
4. Verify example values (temperatures, frequencies, thresholds) against legislation, customer specifications and on-site validation.
5. Approve the document per PR-001 and train employees.
